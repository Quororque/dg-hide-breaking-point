# Delta Green: Hide Breaking Point

A small Foundry VTT module for the Delta Green system. For non-GM users, the Breaking Point counter on agent sheets is hidden. GM/Handler users continue to see the counter normally.

The module does not change the actor's Breaking Point value or the Delta Green system's calculations. It only hides the corresponding sheet UI for players.

Requires Foundry VTT 14 and the Delta Green system (2.0.0).
